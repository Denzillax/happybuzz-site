### Task P1: Hero-Standzeit pro Slide

**Files:** Modify `src/components/home/Hero.tsx` (slides-Array + Rotations-Effect)

- [ ] Beta-Slide erhält `dwell: 12000`. Effect ersetzen:

```tsx
useEffect(() => {
  // Standzeit pro Slide (Beta laenger): setTimeout-Kette statt festem Interval
  const dwell = slides[current].dwell ?? 6500
  const t = setTimeout(() => {
    setTransitioning(true)
    setTimeout(() => { setCurrent(c => (c + 1) % slides.length); setTransitioning(false) }, 350)
  }, dwell)
  return () => clearTimeout(t)
}, [current])
```

- [ ] Live: Beta-Slide steht ~12s, andere ~6.5s. Commit `feat(hero): Beta-Slide steht 12s`.
